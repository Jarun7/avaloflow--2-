# AvaloFlow Documentation

AvaloFlow is a web application for managing workflows and automation.

## Features
- Dashboard for overview.
- Flow Builder for creating workflows.
- Analytics for monitoring performance.
- Library for managing assets.

## Testing
- Unit tests are run using Vitest.
- E2E tests are run using Playwright.

## Running Tests
- Unit tests: `npm run test:unit`
- E2E tests: `npm run test:e2e`
